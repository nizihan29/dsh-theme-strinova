# dsh-theme-strinova · 卡拉彼丘主题

![预览](assets/screenshot.png)

**喵拉喵丘喵了喵！**  
给 DeepSeek Harness 做的一套卡拉彼丘主题喵，包含：浅色 / 深色两套、角色卡随机轮换（台词 + 右下角q版表情包）、漂浮粒子、侧边栏自定义logo。

## 安装

### 方式一：直接安装（推荐）

1. 打开 DSH → **插件**
2. 点 **添加插件**
3. **安装源** 选 **npm 官方源**
4. 输入 `dsh-theme-strinova`，点安装

### 方式二：插件市场

1. 打开 **插件市场**
2. 搜索 `dsh-theme-strinova`
3. 点安装
